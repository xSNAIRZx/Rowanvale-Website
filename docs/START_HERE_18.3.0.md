# Start Rowanvale 18.3.0 on Windows

1. **Before upgrading** open your current Rowanvale through its local Node server and use **Data & Beta → Export backup**. Preserve the old ZIP and folder.
2. Install Node.js 18 or newer if needed. Extract the **whole 18.3.0 ZIP** to a new folder, not over your old one.
3. Double-click **`START_ROWANVALE_WINDOWS.bat`** in the extracted root folder. Leave its terminal running.
4. Visit **http://localhost:8080** in your regular browser. Don't double-click `index.html` to open a `file:///` address; that will not use the local server and has separate saved browser data.
5. In the left rail choose **Games & Media**. Open **Books Directory** for 107 offline book starters, manual book entry, and optional Open Library search. For search, both Node and internet must be available; there is no provider key to configure.
6. To see XP, save a book, choose **Log pages**, and enter the furthest page reached. XP is recorded only once per milestone. You may change the page count in **Update reading** to match your edition.
7. Keep backups periodically. Rowanvale is still a private, local browser-based desktop beta; it is not an independently verified secure multi-user account service or signed Windows installer.

**If you need to use the same port as your old copy:** close any older Rowanvale server before starting 18.3.0. Keeping the same browser profile and `localhost:8080` is important for retaining saved data.
