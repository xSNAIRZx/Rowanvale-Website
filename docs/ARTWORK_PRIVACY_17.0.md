# Art, privacy and attribution (17.0 beta)

Rowanvale's seeded game names and descriptions are not a publisher-licensed bulk artwork pack.

You can attach personal imagery you own or are permitted to use. Original uploaded JPG/PNG/WebP images are transformed in-browser to compact JPEG thumbnails before they're stored in the existing saved workspace. This is a local beta image manager, not an infinite media library.

You can also request metadata image candidates from the local `/api/games?search=...` proxy, which uses third-party sources only when asked. Review actual game editions and license terms before setting an image. Rowanvale deliberately doesn't auto-select similar titles or bundle downloaded third-party images. URLs may make requests to image hosts and may be subject to that host's conditions.

The original Rowanvale account mode is browser-local. The data backup contains uploaded covers and personal settings; treat the JSON as private, especially if it also contains wellness, friend or food data.

Steam and RAWG are names of third-party catalog services; use of their data doesn't imply endorsement. Review provider documentation, applicable terms and image distribution permissions before launching any public or commercial deployment.
