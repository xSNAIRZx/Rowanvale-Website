# The Fan Lounge — 18.2

Open Games → Fan Lounge, mobile More → Fan Lounge, or Explore the lounge from the Watch Room / Games pages. Existing watch and game records stay in the same collection.

## Find, compare, collect

The bundled directory contains 1,199 movies, 499 TV series and 500 anime entries from public Wikidata metadata, plus the existing Rowanvale game index. It also includes your manually saved titles. Search by title, genre or year; filter by format, genre/mood or saved status, and sort by title, year or known runtime. Results are paginated in groups of 24. The directory has no network dependency after the installed shell is cached. It also loads from local bundled files.

Save adds the title to the existing Watch Room or Games collection. Compare places up to four contenders side by side, including runtime when known, genres, saved status and your recorded watch rating. Comparison selection is temporary and resets on reload; convert it into a night to keep the picks.

Create shelves for personal themes, seasons, franchises or moods. Shelf + uses the current shelf, selectable in the directory's Add picks to panel. Shelves can be renamed, described, edited, deleted or exported as plain title lists. Removing a shelf does not delete collection records. Limits: 30 shelves, 100 titles each.

## Make a night of it

Make a plan from comparisons or start an empty night. Add a name, date/time, location, time budget, break length, guest names and notes. Nominate movies, episodes, anime or games from the directory; change the destination in Add picks to. Limits: 20 plans, 24 contenders per plan, 12 uniquely named guests.

Pass the device around: select Voting as and vote Yes (2), Maybe (1) or No (0). A new vote replaces that guest's old vote on the same title. Ties are displayed honestly. These are local guest labels, not authenticated accounts or tamper-proof ballots.

Choose In the lineup and set each slot's planned minutes. Movie runtime may prefill; TV/anime blocks and game sessions need your own estimates when unknown. Move earlier changes order. The schedule adds breaks and warns about missing durations or budget overruns. A missing duration makes later start times TBD. Date/time is the host's local time, without cross-timezone conversion.

## Share deliberately

Share / export opens a review. Invitation text includes location, notes, running order and vote totals. Editable JSON also includes guest names and individual votes. Neither exports your full workspace, profile, private collection notes or covers. A download is not sent automatically. Importing a plan creates an independent local copy and asks you to review it; it does not merge or sync ballots with the sender.

Workspace JSON backups include plans and shelves. Export a backup before upgrading or clearing browser data. Failed writes retain existing data. Conflicting writes from another tab require reload.

## What stays for later

Hosted friend accounts, live syncing, feeds, messaging, notifications and streaming playback are not included. The user chose hosted social features as a later phase. The current release provides shared-device planning and manual portable sharing. No service credentials or hosting setup are required.

## Design references

[Letterboxd](https://letterboxd.com/welcome/) describes watchlists, personal lists, ratings and diary patterns. [Plex Discover](https://www.plex.tv/discover/) describes unified entertainment discovery and social recommendations. [Backloggd](https://backloggd.com/about/) describes game collections and tracking. Rowanvale adapts these broad patterns to private local data, with its own design and a group-night planner. No affiliation, brand assets, scraped reviews or copied proprietary databases.
