# Watch Room — Rowanvale 18.1

Movies, anime and TV shows share one local collection. Existing media in the backlog appears automatically. Use Movies, Anime & TV in the sidebar or More on mobile.

Add titles manually, set watch status, rate them, favorite them, record private notes and track seasons and episodes. Completing the known episode total marks a series completed. Movie watches and episode updates feed a viewing diary. Search/filter your saved collection or let the picker select an unfinished title from the current filters. Unknown episode totals remain unknown. Removing a title offers one-step undo during the session.

## Local by default

No account or catalog connection is required. Titles, notes, ratings, progress and uploaded covers are saved in the existing browser workspace and included in JSON backups. The app can reload offline after its shell has been cached by a successful localhost visit. Keep the same browser profile and localhost address. Browser clearing/private browsing and storage quotas still apply; export backups regularly.

PNG/JPEG/WebP covers are resized locally and stored with the title. External posters are not fetched automatically. This is a tracker, not a video player or streaming service.

## Optional discovery

Enable online search explicitly, select a format, enter a title and press Search online. Only the query and selected format are sent; private notes and your collection are not uploaded. Choose a result to save its metadata locally. Manual entry remains available during catalog outages. Search needs the bundled local Node server and internet access. No API key is required for these providers.

Films: [Wikidata data access](https://www.wikidata.org/wiki/Help:Data_access), public structured data under CC0. Film classification and results can be incomplete.
Anime: [AniList API](https://docs.anilist.co/guide/graphql/). Public metadata; provider terms apply.
TV: [TVmaze API](https://www.tvmaze.com/api), attribution shown in the UI; TVmaze data uses CC BY-SA.

The watchlist/diary/rating workflow draws on established patterns described by [Letterboxd](https://letterboxd.com/faq/); episode progress uses the kinds of metadata supported by AniList and TVmaze. Rowanvale does not claim affiliation with these services or copy their branding.
