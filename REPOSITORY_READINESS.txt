HOW TO REPRODUCE

Run npm start for the original local app; use PORT=4175 in the process environment if desired. Default port is 8080. Follow README.md for authenticated hosting and migration.
Browser dependencies: npm exec playwright install chromium for the full browser suite. The hosted browser check defaults to installed Chrome on Windows; set ROWANVALE_BROWSER to an installed compatible browser executable elsewhere.
